Open standards

Seven open standards for AI written code

Each standard pairs a public domain specification with a free tool, so any team, vendor or open source project can adopt it in one command. Each has its own page at oss.korext.com.

Platform

One platform enforces your rules where code is written

The Korext Platform checks human written and AI generated code against security, regulatory and engineering policies, in the editor, the terminal, the pull request and the AI assistant itself. It is a commercial product; learn more at korext.com.

72 policy packs, 532 rules

Packs such as web, OWASP, PCI DSS, HIPAA and GDPR, across 13 languages. Combine several packs in one scan.

A signed proof bundle for every scan

Each decision to pass, warn or block records the policy version, every check that ran, the evidence and where the code was processed, ready for an audit.

Processing in your region

Choose the US, the EU or Asia Pacific for each scan, so the proof shows where the code was processed and stored.

Gate every pull request with one workflow file, .github/workflows/korext.yml. Violations appear as Code Scanning annotations on the diff, and the check fails on critical or high severity findings.

# .github/workflows/korext.yml
name: Korext Enforcement
on: [push, pull_request]
permissions:
  contents: read
  security-events: write
jobs:
  enforce:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: Korext/enforce-action@v3
        with:
          api-token: ${{ secrets.KOREXT_API_TOKEN }}

FAQ

Questions teams ask first

What is Korext?

Korext makes AI generated code accountable. It publishes seven open standards that make AI written software traceable, licensable and accountable, and runs the Korext Platform, which enforces your policies where code is written and signs a proof bundle for every scan.

Which AI coding tools does ai-attestation detect?

Nineteen: GitHub Copilot, Cursor, Claude Code, Windsurf, Codeium, Aider, Devin, OpenHands, Amazon Q Developer, OpenAI Codex CLI, Gemini Code Assist, JetBrains AI, Sourcegraph Cody, Tabnine, Replit AI, Cline, Continue, GPT Engineer and Bolt. It reads publicly observable signals such as co-author trailers, commit messages, file headers and git config. Add a tool.

Are the Korext open standards free to use?

Yes. Specifications and schemas are CC0 1.0 (public domain), code and tools are Apache 2.0, and data is CC BY 4.0. The Korext Platform is a separate commercial product.

What is a Korext proof bundle?

A signed record of one governance decision: whether the change passed, warned or was blocked, which policy version was active, every check that ran, the evidence, and where the code was processed. It can be exported for audits and incident reviews.

Where does the Korext Platform run?

In VS Code, in Cursor and Windsurf through Open VSX, in JetBrains IDEs, in the terminal through the korext CLI on npm, in GitHub pull requests through the Korext Enforce action, in Chrome, and in AI assistants through MCP. Processing can run in the US, the EU or Asia Pacific.

How do I add Korext to my pull requests?

Add a workflow that uses Korext/enforce-action@v3. It installs the Korext CLI, scans the code with the policy packs you choose, uploads the results to GitHub Code Scanning so violations appear on the pull request, and fails the check on critical or high severity findings. See enforce-action.

Who builds Korext?

Korext was founded by Tom Bruno, who leads the open standards as lead maintainer. Contributors are welcome on every standard; write to maintainers@korext.com.

# korext.github.io

The source of [korext.github.io](https://korext.github.io), the Korext home on GitHub: seven open standards and the Korext Platform for AI generated code.

It is one static page with no build step and no tracking. GitHub Pages serves this branch as it is.

| File | What it is |
| --- | --- |
| `index.html` | The page, with Open Graph tags and JSON-LD for the organization, the platform, the seven standards and the FAQ |
| `assets/korext.css` | The Coast to Dunes styles, shared with [tbrunoh.github.io](https://tbrunoh.github.io) |
| `assets/*.svg` | The hero, the stack diagram and the contours, with every word drawn as outlines |
| `llms.txt`, `llms-full.txt` | A summary and the full text for AI agents |
| `sitemap.xml`, `robots.txt` | For search engines |
| `404.html` | The not found page |

Fonts are Inter and Newsreader under the SIL Open Font License (`assets/fonts/OFL.txt`).

To change the open standards themselves, see their repositories under [github.com/korext](https://github.com/korext). For questions, write to [maintainers@korext.com](mailto:maintainers@korext.com).
